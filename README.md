# 🧠 Think – Task Manager

![Python](https://img.shields.io/badge/python-3.8%2B-blue?logo=python&logoColor=white&style=for-the-badge)
![PySide6](https://img.shields.io/badge/PySide6-5A9?logo=qt&logoColor=white&style=for-the-badge)

A simple and elegant **task manager** built with **Python**. I have created it as hobby project. We can save our tasks and it handles our all tasks by giving remainder.


## ✨ Features  
- ✅ Add, edit, and delete tasks  
- ⚡ Lightweight, no heavy dependencies 
- ⏰ Tasks Reminder

# 📦 Installation & Setup
```bash
# 1️⃣ Clone the repositor
git clone https://github.com/talhausmandev/Think-TaskManager.git

# 2️⃣ Navigate into the project folder
cd Think-TaskManager

# 3️⃣ Install dependencies
pip install -r requirements.txt

# 4️⃣ Start App
python Think.py
```
